# stop-hour-heatmap

정류장(행) x 시간대(열) 히트맵을 **외부 라이브러리 없이 단일 HTML 파일**로 만든다. 노선 드롭다운으로 노선별 보기를 바꿀 수 있고, 모든 옵션이 같은 색 기준을 쓴다.

참고 구현은 저장소의 `analysis_congestion.py`다. 새 지표를 만들 때는 이 파일을 복사해 집계 함수와 설명 문구만 바꾼다. 색과 레이아웃 규칙은 [references/visual-rules.md](references/visual-rules.md)에 있다. **HTML을 쓰기 전에 반드시 읽는다.**

## 워크플로

### 1. 지표 정의

요청이 말하는 것을 데이터 컬럼에 대응시킨다. 대응이 완전하지 않으면 **대리 지표라고 명시**한다.

| 요청 | 컬럼 | 비고 |
|---|---|---|
| 혼잡도 | 없음 | 하차(`alight_cnt`)를 대리 지표로 쓰고, 본문과 주석에 명시 |
| 하차 인원 | `alight_cnt` | 그대로 사용 |
| 환승 인원 | `transfer_cnt` | 그대로 사용 |

차량 정원이나 승차 데이터가 없으면 "실제 혼잡도(차내 인원/정원)와 다르다"는 문구를 HTML 각주에 넣는다.

### 2. 집계

- 값은 **일평균**으로 쓴다: 기간 전체 합 / 일수. 날짜가 빠진 시간대는 0으로 본다.
- 옵션은 `전체`와 노선별 하나씩 만든다. 노선별 집계는 `route_id` 필터 후 같은 함수를 쓴다.
- 행 순서는 `전체` 합계 내림차순으로 **한 번만 정하고 고정**한다. 노선을 바꿔도 정류장 위치가 바뀌지 않아야 한다.
- 시간대는 데이터에 실제로 있는 범위만 쓴다 (예: 5~23시).
- 정류장 이름은 `bus_routes.xlsx`의 `routes` 시트에서 `stop_id`로 붙인다. 이름이 중복되면 `stop_id`를 같이 표시한다.

### 3. 색

- **순차(sequential) 단일 색조**로 칠한다. 값이 0에 가까우면 밝고, 클수록 진해진다.
- 모든 옵션의 색 기준은 **전체 옵션 중 최댓값 하나**로 맞춘다. 노선마다 최댓값으로 맞추면 노선끼리 색을 비교할 수 없다.
- 밝은 쪽과 어두운 쪽 값은 [references/visual-rules.md](references/visual-rules.md)의 팔레트에서 가져온다. 다크 모드는 같은 계열의 다른 단계를 쓴다.
- 진한 셀에서는 글자색을 밝게 바꾼다.
- 색은 값을 나타낼 뿐 정류장이나 노선의 식별 수단이 아니다. 식별은 행·열 라벨로 한다.

### 4. HTML 구성

단일 파일로 만든다. 데이터는 JSON으로 `<script>` 안에 넣는다.

- 상단: 제목, 분석 기간, 시간대 범위
- 컨트롤: 노선 드롭다운, 범례(그라디언트 + 최댓값 표기)
- 본문: 표 형태 히트맵. 셀에 값이 1 이상이면 정수로 표시한다.
- 셀 호버: 정류장, 시간대, 값을 담은 툴팁. 셀 자체보다 넓게 마우스를 받을 필요는 없다.
- 각주: 지표 정의, 데이터 출처, 대리 지표 여부, 행 정렬 기준
- 작은 화면에서 가로 스크롤이 생기도록 감싼다. 페이지 전체가 깨지면 안 된다.
- 다크 모드: `prefers-color-scheme`를 따르고, 변경 시 다시 그린다.

### 5. 검증

1. **합계 대조:** `전체` 옵션 합계가 노선별 합계의 합과 같은지 확인한다 (반올림 오차 범위).
2. **문법 검사:** HTML의 `<script>` 블록을 꺼내 `node --check`로 확인한다.
3. **렌더 확인:** 브라우저로 열어 표와 범례가 보이는지 본다. 브라우저를 열 수 없으면 그 사실을 사용자에게 말하고, 렌더 확인을 하지 못했다고 명시한다. 확인하지 않은 것을 확인했다고 쓰지 않는다.
4. **상위 셀 확인:** 가장 진한 셀과 시간대별 합계를 계산해 본문 요약과 맞는지 본다.

### 6. 결과 보고

- 파일 경로와 생성 스크립트 경로를 알려준다.
- 지표 정의(대리 지표 여부), 분석 기간, 데이터가 더미인지 밝힌다.
- 핵심 관찰 1~2가지를 숫자와 함께 적는다. 확인하지 않은 수치는 쓰지 않는다.

## 하지 않는 것

- 외부 CDN이나 차트 라이브러리를 쓰지 않는다. 단일 HTML로 오프라인에서도 열려야 한다.
- 이중 축을 쓰지 않는다. 지표가 둘이면 히트맵을 두 개 만든다.
- 정류장을 무작위 색으로 구분하지 않는다. 행 라벨로 구분한다.
- 승인 없이 커밋하거나 푸시하지 않는다.
