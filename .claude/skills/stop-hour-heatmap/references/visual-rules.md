# 히트맵 시각화 규칙

이 문서는 `stop-hour-heatmap` 스킬의 색과 레이아웃 기준이다. 값은 `analysis_congestion.py`에서 실제로 쓴 것이다.

## 색 (순차, 파랑 계열)

밝은 쪽 = 낮은 값, 진한 쪽 = 높은 값.

| 모드 | 램프 (낮음 → 높음) |
|---|---|
| 라이트 | `#cde2fb` → `#9ec5f4` → `#6da7ec` → `#3987e5` → `#256abf` → `#104281` → `#0d366b` |
| 다크 | `#104281` → `#184f95` → `#1c5cab` → `#256abf` → `#2a78d6` → `#3987e5` → `#86b6ef` |

- 라이트 표면 `#fcfcfb`, 다크 표면 `#1a1a19`, 페이지 배경은 각각 `#f9f9f7`, `#0d0d0d`.
- 주 글자색: 라이트 `#0b0b0b`, 다크 `#ffffff`. 보조 글자색: `#52514e`, `#c3c2b7`.
- 셀 값이 최댓값의 55%를 넘으면 글자를 `#ffffff`로 바꾼다.
- 셀 사이 간격은 2px로 두고, 간격은 표면색으로 채운다.

## 색 기준

- 모든 옵션에 같은 최댓값을 쓴다 (`max` = 전체 옵션 포함 모든 셀의 최댓값).
- 0은 램프의 가장 밝은 단계로 칠한다.
- 범례에는 최댓값을 적는다.

## 레이아웃

- 최대 너비 약 1100px, 좌우 여백 16px.
- 표는 `overflow-x: auto`로 감싼다. 셀 크기는 약 34x24px.
- 행 라벨은 오른쪽 정렬, 열 라벨은 가운데 정렬.
- 컨트롤(노선 선택, 범례)은 표 위 한 줄에 둔다. 좁으면 줄바꿈한다.

## 상호작용

- 셀 호버 시 외곽선 2px, 툴팁에 `정류장 · 시간대 · 값` 표시.
- 툴팁은 `position: fixed`로 커서를 따라간다.
- 노선 변경 시 표 전체를 다시 그린다. 행 순서는 바뀌지 않는다.

## 문구

- 셀 값의 의미(일평균 인원)를 표 아래 각주에 적는다.
- 대리 지표이면 그 사실과 실제 혼잡도와의 차이를 각주에 적는다.
- 더미 데이터이면 "더미 데이터 기준"이라고 명시한다.
