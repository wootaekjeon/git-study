# 라벨 목록

이 저장소의 라벨은 **전부 한글**로 쓴다. 기존 영문 기본 라벨(`enhancement`, `bug`, `documentation` 등)은 그대로 두고, 아래 한글 라벨을 새로 만들어 쓴다.

라벨 생성 명령 형식:

```bash
gh label create "<이름>" --color "<색상코드>" --description "<설명>" --force
```

1. `gh label list --limit 100`으로 현재 라벨을 확인한다.
2. 위 표에서 없는 라벨만 만든다 (`--force`를 붙이면 이미 있어도 안전하다).
